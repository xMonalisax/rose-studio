# Rose Studio

A web application for managing appointments in a beauty salon.

## Technologies Used

- **Frontend:** React + Vite
- **Backend:** Node.js + Express
- **Database:** MySQL
- **ORM:** Prisma
- **Styling:** Custom CSS

## Implemented Improvements

- Redesigned user interface with a light pink color scheme
- Enhanced administrator dashboard
- Statistics and charts accessible only to administrators
- Estimated revenue, occupancy rate, most popular services, and top clients
- Individual work schedules for each employee
- Custom break times for each employee
- Employee unavailability and vacation management
- Automatic recommendations for available appointment slots
- Automatic 10-minute buffer between appointments
- Appointment cancellation allowed only at least 4 hours in advance
- Client appointment history and simplified loyalty tracking

## Features

### Client

- Register and log in
- Browse available services
- View service prices
- Book appointments
- Receive recommendations for available time slots
- View upcoming appointments and complete appointment history
- Track estimated total spending and favorite service
- Cancel appointments

### Employee

- Log in
- View only their assigned appointments
- View personal work schedule and break times
- Accept, reject, complete, or mark appointments as no-shows

### Administrator

- Log in
- Add and manage services
- Add employees
- Configure employee work schedules and break times
- Manage employee unavailability and vacation days
- View all appointments
- Access statistics and charts
- Receive promotional suggestions for the most requested service
