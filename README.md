# Rose Studio

Aplicație web pentru gestionarea programărilor într-un salon de înfrumusețare.

## Tehnologii folosite
- Frontend: React + Vite
- Backend: Node.js + Express
- Baza de date: MySQL
- ORM: Prisma
- Stilizare: CSS simplu personalizat

## Îmbunătățiri adăugate
- interfață vizuală refăcută pe nuanțe de roz deschis
- dashboard administrator mai complex
- statistici și grafice vizibile doar pentru administrator
- venit estimat, grad de ocupare, top servicii, top clienți
- program diferit pentru fiecare angajat
- pauză pentru fiecare angajat
- zile indisponibile / concedii pentru angajați
- recomandări automate de intervale libere
- pauză automată de 10 minute între programări
- anulare permisă doar cu minimum 4 ore înainte
- istoric client și fidelizare simplificată

## Funcționalități incluse
### Client
- register și login
- vede servicii
- vede lista de prețuri
- face programare
- primește recomandări de intervale disponibile
- vede programările lui și istoricul complet
- vede suma estimată cheltuită și serviciul preferat
- poate anula o programare

### Angajat
- login
- vede doar programările proprii
- vede programul personal și pauza
- acceptă / respinge / finalizează / marchează ca neprezentat

### Admin
- login
- adaugă servicii
- adaugă angajați
- setează programul și pauza angajaților
- adaugă zile indisponibile
- vede toate programările
- vede statistici și grafice
- primește sugestie de promoție pentru cel mai cerut serviciu
